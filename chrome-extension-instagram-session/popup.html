Instagram Session Bridge

Скачивает JSON с действующей Instagram-сессией для ScanerBlogers.

Откройте instagram.com в этом браузере и войдите в аккаунт.
Как использовать
  1. Войдите в нужный Instagram-аккаунт в этом браузере.
  2. Нажмите «Прочитать sessionid».
  3. Скачайте JSON.
  4. Загрузите JSON на странице подключения Instagram в ScanerBlogers.
